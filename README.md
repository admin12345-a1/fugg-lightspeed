# FUGG // GameForge

An offline, document-local game director. Each run rolls a new seed, art direction, title, and playable rule set. Current grammars include salvage, stealth courier, survival gardening, orbital defense, and ruin exploration.

[Play FUGG // GameForge on GitHub Pages](https://admin12345-a1.github.io/fugg-lightspeed/)

Open `index.html` directly in a browser. Press **Generate another game** for a different world. The generated seed is shown in the director card so a run can be replayed or shared later.
